# DevfSeek - Clon de ChatGPT

## 📌 Descripción

DevfSeek es un clon de ChatGPT construido paso a paso con React y Express. Este repositorio contiene la **Parte 1** del proyecto: configuración inicial con Vite, Tailwind CSS y React Hook Form.

## 🚀 Parte 1: Configuración y Formularios

- Proyecto creado con Vite + React.
- Estilos con Tailwind CSS.
- Formulario validado con React Hook Form.
- Input para enviar mensajes (simulación).

## ⚙️ Cómo Ejecutar

```bash
npm install
npm run dev
